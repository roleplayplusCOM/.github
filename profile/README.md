**atelier** is our free, open-source tool for GTA V addon clothing. Manage drawables in a workbench, author tattoos, check everything in real-time 3D and build an in-game-ready addon in one click. It works offline and needs no account.

#### Repositories

- [**atelier**](https://github.com/roleplayplusCOM/atelier): the Windows desktop app, built with Tauri and React.
- [**atelier-api**](https://github.com/roleplayplusCOM/atelier-api): the optional backend. Discord login, team cloud with live collaboration, storage and server builds.
- [**atelier-fivem**](https://github.com/roleplayplusCOM/atelier-fivem): the in-game viewer. It finds your packs on the server and lets you browse them on a real ped. In development.

#### What atelier does

- **Real-time 3D preview**: several drawables at once, camera presets, poses, optionally on the real ped body.
- **Workbench**: category tree, searchable drawable list, inspector, textures a–z and duplicate detection.
- **Tattoos**: import decals, set zone, gender and draw order, build a streamable tattoo pack.
- **One-click build**: real `CPedVariationInfo` YMTs, automatic 128-split, shop metas and `fxmanifest.lua`.
- **Texture optimisation**: BC1, BC3 and BC7 re-encode, downscale and mips, one by one or in bulk.
- **Team cloud** (optional): edits show up live on every connected client.
